# Excerly – יומן כושר ביתי 🧘‍♂️

אפליקציית ווב (PWA) לכושר ביתי המתמקדת בתרגילי מתיחה, עם **אנימציה לכל תרגיל**,
תזכורות יומיות, ומחשבון BMI וקלוריות. כל הנתונים נשמרים במכשיר בלבד (localStorage).

## תכונות עיקריות

- 📅 **יומן אימונים** – לוח שנה חודשי. לחיצה על יום פותחת חלון עם האימון של אותו יום.
- 🏃 **תרגילים מונפשים** – לחיצה על תרגיל מציגה אנימציית SVG של ביצוע התנועה,
  מספר החזרות, זמן ההחזקה, הוראות שלב-אחר-שלב וטיפ.
- 🗓️ **תוכנית שבועית** – מיקוד שונה בכל יום (פלג עליון, גב וליבה, פלג תחתון,
  מנוחה פעילה, גמישות מלאה ועוד).
- ⏰ **תזכורת יומית** – הגדרת שעה וקבלת התראה יומית לאימון (Web Notifications).
- ⚖️ **מחשבון BMI וקלוריות** – הזנת גיל, משקל, גובה, מין ורמת פעילות מחשבת
  BMI, קלוריות יומיות (נוסחת מיפלין-סנט ג'ור), חלוקת מאקרו והמלצות תזונה.
- 🍎 **מעקב תזונה יומי מבוסס AI** – כתיבת מה שאכלתם כטקסט חופשי; **Claude**
  מבין את הטקסט ומחשב את הקלוריות, ומוצג אם עמדתם ביעד היומי או חרגתם ממנו.
  כפתור נוסף בונה תפריט יומי מגוון לפי כמות הקלוריות. ה-AI מחובר דרך שרת
  **proxy** (Cloudflare Worker) שמחזיק את מפתח ה-API בצד השרת — כך שהניתוח
  החכם עובד לכל מי שנכנס לאתר, בלי לחשוף מפתח (ראו `worker/README.md`).
  ללא חיבור, פועל מנוע הערכה **מקומי** (לא מקוון) כגיבוי.
- 🔥 **מעקב רצף** – ספירת ימי אימון רצופים וסך האימונים שהושלמו.
- 🌐 **שפת ממשק** – מתג עברית / English (כולל היפוך RTL/LTR); כל התוכן,
  התרגילים וההמלצות דו-לשוניים, וה-AI עונה בשפת הממשק. הבחירה נשמרת במכשיר.
- 📱 **PWA** – ניתן להתקנה במסך הבית ועובד גם לא-מקוון.

## הרצה

זוהי אפליקציה סטטית ללא שלב build. יש להגיש את התיקייה משרת סטטי כלשהו:

```bash
# לדוגמה עם Python
python3 -m http.server 8080
# ואז לפתוח http://localhost:8080
```

> הערה: התזכורות (Web Notifications) וה-Service Worker דורשים הגשה דרך `http(s)://`
> (או `localhost`) – הם אינם פעילים בפתיחת הקובץ ישירות דרך `file://`.

## מבנה הפרויקט

```
index.html              – מבנה העמוד והרכיבים
manifest.webmanifest    – הגדרות PWA
sw.js                   – Service Worker (offline)
assets/
  icon.svg              – אייקון האפליקציה
  css/app.css           – עיצוב + הגדרות אנימציות התרגילים
  js/
    data.js             – מאגר התרגילים, התוכנית השבועית ולוגיקת BMI/תזונה
    animations.js        – בניית דמויות ה-SVG לכל תרגיל
    nutrition.js        – הערכת קלוריות מטקסט חופשי + מחולל תפריט (AI + מקומי)
    app.js              – לוגיקת האפליקציה (יומן, חלונות, תזכורות, פרופיל, תזונה)
worker/
  excerly-proxy.js      – Cloudflare Worker proxy ל-Claude (מחזיק את המפתח)
  wrangler.toml         – הגדרות פריסה של ה-Worker
  README.md             – הוראות פריסה וחיבור ה-AI
```

## הערה בנוגע ל-BMI

חישוב ה-BMI מחייב **גובה** בנוסף לגיל ולמשקל, ולכן נוסף גם שדה גובה.
המידע באפליקציה הוא לצורכי מידע כללי בלבד ואינו מחליף ייעוץ רפואי מקצועי.
